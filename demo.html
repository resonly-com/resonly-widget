Resonly Widget Demo v1.0

Self-contained embeddable feedback widget with no network calls

1. Default Initialization

The widget auto-initializes on page load with default settings.

Position: bottom-left
Accent Color: #7c3aed (purple)
Storage: localStorage only

Look at the bottom-left corner to see the widget with 3 buttons: Feedback, Issue, Idea.

3. Per-Type Questions

Different questions for each feedback type:

ResonlyWidget.init({
  buttons: [
    {
      type: 'feedback',
      label: 'Feedback',
      icon: '💬',
      question: 'How can we improve?'
    },
    {
      type: 'issue',
      label: 'Issue',
      icon: '🐛',
      question: "What's broken?"
    }
  ]
});

7. Custom Buttons & Styles

Configure custom buttons with their own labels, icons, and styles:

// Configure buttons
buttons: [{
  type: 'bug',
  label: 'Report Bug',
  icon: '🔥',
  question: 'Describe the bug',
  style: { backgroundColor: '#ef4444' }
}],

// Configure every form element
formStyle: {
  panel: { background: '#f3f4f6', borderRadius: '20px' },
  panelTitle: { fontSize: '20px', color: '#7c3aed' },
  textarea: { minHeight: '150px', fontSize: '16px' },
  submitButton: { padding: '12px 32px', background: '#10b981' }
}
